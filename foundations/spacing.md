# فاصله‌گذاری و شبکه سیمرغ

## مقیاس فاصله

بر پایه یک واحد پایه (پیشنهاد: `4px`):

| توکن | مقدار | کاربرد |
|---|---|---|
| `space.1` | `0.25rem` (4px) | فاصله‌های خیلی ریز |
| `space.2` | `0.5rem` (8px) | داخل کامپوننت‌ها |
| `space.3` | `0.75rem` (12px) | فاصله عناصر مرتبط |
| `space.4` | `1rem` (16px) | فاصله استاندارد |
| `space.6` | `1.5rem` (24px) | فاصله گروه‌ها |
| `space.8` | `2rem` (32px) | فاصله بخش‌ها |
| `space.12` | `3rem` (48px) | فاصله‌های بزرگ |
| `space.16` | `4rem` (64px) | فاصله بخش‌های صفحه |
