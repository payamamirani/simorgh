# پالت رنگ سیمرغ — نسخه ۱

> فیروزه‌ایِ خاموش + خاکستری گرم + رنگ‌های معنایی ملایم (مینیمال)

منبع اصلی حقیقت: `packages/tokens/tokens/` — این فایل فقط خلاصه و توضیح است.

## معماری دو لایه

```
پالت خام (palette.tokens.json)     ← مخزن رنگ — هرگز مستقیم استفاده نمی‌شود
        ↓ ارجاع
توکن‌های معنایی (themes/*.json)    ← نقش‌ها: primary, surface, text, ...
        ↓ Style Dictionary
CSS Variables + Tailwind           ← آنچه کامپوننت‌ها مصرف می‌کنند
```

**قاعده‌ی طلایی:** کامپوننت فقط نقش می‌بیند (`bg-primary` ✅ / `bg-teal-700` ❌). تم تیره فقط با `data-theme="dark"` روی `<html>` فعال می‌شود.

## دسترس‌پذیری

- همه‌ی ۱۸ جفت حیاتی (متن/پس‌زمینه در هر دو تم) توسط `scripts/check-contrast.mjs` **در هر بیلد** چک می‌شوند و رد شدن هر جفت، بیلد را متوقف می‌کند.
- استاندارد: حداقل `4.5:1` برای متن (WCAG 2.x AA).
