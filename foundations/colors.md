# پالت رنگ سیمرغ

## ساختار

| نقش | توضیح |
|---|---|
| **Primary** | رنگ اصلی برند — برای اکشن‌های اصلی |
| **Neutral** | رنگ‌های خنثی — متن، پس‌زمینه، خطوط |
| **Semantic** | موفقیت، خطا، هشدار، اطلاعات |
| **Surface** | سطوح و لایه‌های رابط کاربری |

## مقیاس

هر رنگ در ۱۰ سطح تعریف می‌شود (مثل `50` تا `900`):

```
color.primary.50   → روشن‌ترین (پس‌زمینه‌های ملایم)
color.primary.500  → رنگ اصلی
color.primary.900  → تیره‌ترین
```
