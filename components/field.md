# Field

> سیم‌کشی خودکار دسترس‌پذیری فرم — لیبل، راهنما، خطا و الزامی را به هر کنترلی وصل می‌کند.

## دمو

زنده در Storybook: `Forms/Field` — استوری «فرم کامل» را حتماً ببین.

## API

| نام | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `label` | `ReactNode` | — | لیبل — با `htmlFor` به کنترل وصل می‌شود |
| `hint` | `string` | — | راهنمای عادی (خاکستری) |
| `error` | `string` | — | پیام خطا — `aria-invalid` روی کنترل + متن قرمز |
| `required` | `boolean` | `false` | ستاره‌ی قرمز + `aria-required` |
| `children` | `ReactElement` | — | کنترل فرم (Input، Select، Textarea و...) — id و aria وصل‌ها خودکار تزریق می‌شوند |

## دسترس‌پذیری (خودکار!)

- `label htmlFor` → کنترل (کلیک لیبل فوکس می‌دهد)
- `aria-describedby` → پیام خطا/راهنما (صفحه‌خوان می‌خواند)
- `aria-invalid` → هنگام خطا (استایل danger هم از همین فعال می‌شود)
- id های یکتا با `useId` — چند فرم در یک صفحه بدون تداخل

## نکات استفاده

- ✅ همه‌ی فرم‌ها — به‌جای دستی نوشتن لیبل/خطا/aria هر بار
- کنترل‌های خودت هم کار می‌کنند تا وقتی prop های تزریقی را spread کنند
- `error` بر `hint` اولویت دارد (همزمان هر دو نشان داده نمی‌شوند)

## توکن‌های استفاده‌شده

`color.text` / `color.text-muted` / `color.danger` · `font.size.caption` · `space.2`
