# Card

> سطح بالا برای گروه‌بندی محتوای مرتبط — API ترکیبی.

## دمو

زنده در Storybook: `Components/Card` (کارت محصول).

## API

| نام | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `as` | `div` \| `section` \| `article` \| `li` | `section` | تگ معنایی |
| `Card.Header` | | | سرصفحه — flex دوطرفه + خط جداکننده |
| `Card.Body` | | | بدنه |
| `Card.Footer` | | | پاصفحه + خط جداکننده |

## نکات استفاده

- ✅ کارت محصول، پنل تنظیمات، خلاصه‌ی سفارش
- محتوا قفل نیست — داخل بخش‌ها هر کامپوننتی (Text، Badge، Button، ...)
- همه‌ی فاصله‌ها و رنگ‌ها توکنی؛ در تم تیره خودکار درست می‌شود

## توکن‌های استفاده‌شده

`color.surface-raised` · `color.border` · `radius.lg` · `shadow.sm` · `space.4/6`
