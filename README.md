# 🪶 Simorgh Design System

سیستم دیزاین **سیمرغ** — مجموعه‌ای از اصول، توکن‌ها و کامپوننت‌ها برای ساخت محصولاتی یکپارچه، زیبا و قابل توسعه.

> مثل سیمرغ که از پرهای بسیاری شکل می‌گیرد، این سیستم از قطعات کوچک و منظم، تجربه‌ای یکپارچه می‌سازد.

## ساختار پروژه

```
simorgh/
├── README.md            # همین فایل — معرفی پروژه
├── docs/                # مستندات و راهنماها
│   └── principles.md    # اصول طراحی سیمرغ
├── foundations/         # پایه‌های طراحی (بنیادها)
│   ├── colors.md        # پالت رنگ
│   ├── typography.md    # تایپوگرافی
│   └── spacing.md       # فاصله‌ها و شبکه
├── tokens/              # توکن‌های طراحی (منبع اصلی حقیقت)
│   └── tokens.json      # توکن‌ها در فرمت استاندارد W3C
└── components/          # مستندات کامپوننت‌ها
    └── _template.md     # قالب استاندارد مستندسازی هر کامپوننت
```

## نقشه راه

- [ ] تعریف اصول و صدای برند
- [ ] پالت رنگ (رنگ‌های اصلی، خنثی، معنایی)

- [ ] سیستم فاصله‌گذاری و شبکه (Grid)
- [ ] توکن‌های پایه (رنگ، فونت، سایه، شعاع گوشه)
- [ ] کامپوننت‌های سطح اول (Button, Input, ...)
- [ ] کامپوننت‌های ترکیبی (Card, Modal, ...)
- [ ] مستندسازی زنده

## نحوه استفاده

هر تغییر در بنیادها (foundations) باید اول در `tokens/tokens.json` اعمال بشه و بعد به مستندات منتقل بشه. توکن‌ها **منبع اصلی حقیقت** (single source of truth) هستن.
